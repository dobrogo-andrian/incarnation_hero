# §1 Структура гри

**Забіг:** генерація персонажа і світу → життя в регіоні → завершення → нарахування резонансу душі → новий забіг.

**Макроцикл.** Гравець розподіляє час між діями: подорож між зонами, чутки, бої, медитація, тренування, лікування, торгівля і взаємодія в поселенні.

**Завершення забігу:**

- смерть у бою або в події;
- вичерпання тривалості життя, зокрема свідома медитація до смерті заради метапрогресії;
- перемога через кризу і фінальний прорив (§11).
