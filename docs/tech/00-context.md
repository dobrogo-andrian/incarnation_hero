# 0 Контекст і межі

**Версія:** 0.1 · **Статус:** чернетка, стек зафіксовано · **Джерело правди про геймплей:** Дизайн-документ MVP

- **Команда:** 1 розробник (C#, досвід Unity; Python; активна робота з ШІ-асистентами), він же єдиний автор контенту.
- **Темп:** 10–15 год/тиждень.
- **Ціль:** публічне демо в Steam з усіма основними механіками, включно з боєм.
- **Платформа:** Windows/Steam. Linux і Steam Deck — побічна мета без гарантій.
- **Візуал:** переважно UI і текст, бій на гекс-сітці з токенами чи іконками. Ассети мінімальні, генеруються ШІ.
- **Мови:** повністю українська. Архітектура готова до англійської та китайської.
- **Бюджет:** мінімальний. Лише безкоштовні та відкриті інструменти.

**Головний технічний принцип.** Гра — це симуляція, а Godot — лише вікно в неї. Усі правила живуть у чистому C#, який запускається без рушія: у тестах, у headless-симуляторі балансу і в грі.
