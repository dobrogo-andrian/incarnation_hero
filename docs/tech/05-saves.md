# 5 Збереження

|  | Сейв забігу | Профіль душі |
|---|---|---|
| Вміст | GameState повністю, стани RNG, знімок і журнал команд поточного бою | Резонанс, ID завершених забігів, статистика, налаштування |
| Формат | JSON + schema_version + контрольна сума | JSON + schema_version + контрольна сума |
| Розташування | user:// | user:// |

**Політика: залізна людина (як у Darkest Dungeon).** Один слот на забіг. Автозбереження після кожної дії. Ручних сейвів і завантаження попереднього стану немає. Вихід із гри можливий будь-коли. Після повернення гравець продовжує з останньої зафіксованої дії.

**Правила:**

1. **Commit-before-reveal.** Будь-який результат, що містить випадковість або нову інформацію (удар, вибір у події, прорив, лут, відкриття зони), записується на диск до того, як UI його покаже.
1. **Тригери запису.** Кожна команда в Overworld, у бою і в діалозі події. Під час багатотижневих активностей запис робиться на кожному перериванні, при завершенні активності, при ручній зупинці та за таймером реального часу (параметр, за замовчуванням ~5 с).
1. **Атомарність.** Запис у тимчасовий файл, потім атомарна заміна. Контрольна сума перевіряється при завантаженні.
1. **Резервна копія.** Зберігається одна попередня версія. Вона використовується лише тоді, коли основний файл не проходить перевірку цілісності. UI не дає доступу до неї як до відкату.
1. **Детермінізм як другий рубіж.** Стани RNG у сейві гарантують, що повтор того самого вибору після креша дає той самий результат.
1. **Кінець забігу:** статус ending → атомарний запис резонансу в профіль з ID забігу → видалення сейву. При старті гра доводить до кінця незавершені ending ідемпотентно.
1. **Продуктивність.** Ціль — запис сейву за кілька мілісекунд. Якщо стан розростеться, переходимо на бінарну серіалізацію або стиснення. Формат не є частиною дизайну.

**Свідомо не захищаємо:** ручне копіювання файлів гравцем. Steam Cloud (відкладено) потребує окремої перевірки щодо відкату версій.

**Сумісність версій.** Сейв забігу може бути інвалідований несумісним оновленням демо, з повідомленням гравцю. Профіль душі мігрує завжди.
