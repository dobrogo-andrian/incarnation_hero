| D22 | Набір категорій переривань, що зупиняють активність, зберігається в стані забігу (за замовчуванням усі); ядро повідомляє й про незупиняючі. Одна команда = один прогін = один автосейв |
| D23 | Перервана активність лишається активною із залишком тижнів: `ContinueActivity`, `CancelActivity` або нова активність замість неї |
| D24 | Попередження про кінець життя — за 5 і за 1 рік до очікуваної тривалості (`life_end_warning_years` у даних) |
| D25 | Два аспекти тілесного стату — його дві ролі з §2.1: Міць — живучість / стійкість, Витривалість — запас / віддача, Швидкість — реакція / верткість, Сила меридіан — ємність / потік (назви тимчасові). Профіль аспектів — частки з сумою 1 на стат; аспект = стат × кількість аспектів × частка (50/50 дає кожному повний стат) |
| D26 | Стартові стати однакові для всіх забігів, задані в YAML; різноманітність дадуть передумови (§2.4) |
| D27 | Максимум ресурсу = база + коефіцієнт × стат або аспект, коефіцієнти в YAML. Пул ці поки має лише базу; внесок чистоти додається в кроці медитації |
| D28 | Модифікатори: (база + ΣAdd) × (1 + ΣMul), потім найменший Cap; Override замінює результат, перемагає найпізніший. Відсотки додаються (+10% і +10% = +20%). Модифікатор від того самого джерела на ту саму ціль замінює попередній |
| D29 | Карта етапу 1 — ручна (хаб + 5 зон у `content/world/region.yaml`), до генерації на етапі 3. `Travel(zoneId)` веде найкоротшим маршрутом (Дейкстра, нічиї — за порядком ID), гравець опиняється в кожній зоні по дорозі; перервана подорож — звичайна активність. Резерв ці місця відновлюється лінійно (`regen_per_week`) до `capacity`. Охорону щільних місць додаємо разом із формульним боєм; доти доступ вільний |
| D30 | Медитація можлива лише в місці медитації поточної зони (у кожній зоні є хоча б одне). Напрям — контент зі швидкістю і ціллю (стат або ресурс): тижневий приріст = швидкість × щільність × ефективність. Тиждень медитації бере з резерву «щільність» одиниць; поки резерв покриває витрату, ефективність повна, інакше резерв / витрата, але не нижче `meditation_depleted_floor`. Переривання «ці місця на мінімумі» — коли резерв уперше перестає покривати тиждень. Чистота — стат; пул ці росте з нею за звичайною формулою ресурсу. Осягнення — окремим кроком разом із фоліантами, засвоєння — разом із бафами |

# 12 Робочі припущення

Ухвалені без підтвердження; змінюються за рішенням автора. Номери закритих A і Q не перевикористовуються.

| # | Припущення |
|---|---|
| A1 | Канонічні тілесні стати — з дизайну §2.1 (Міць, Витривалість, Швидкість, Сила меридіан); §2.7 приводиться у відповідність |
| A2 | Аспекти статів: поле в даних є, у MVP один профіль на метод |
| A3 | Ініціатива — раунди за Швидкістю (див. Q2) |
| A4 | Суперники — статистична модель перехоплення, не агенти |
| A5 | Резонанс нараховується в кінці забігу будь-яким способом |
| A6 | Сейв — один слот, автозбереження, без ручних слотів |
| A8 | Ґатунки духовних каменів: поле в даних передбачене, у MVP один ґатунок |
| A9 | Множина: українські тексти з числами формулюємо без узгодження з числом («Тижнів: 5», а не «5 тижнів»), модуль правил множини не робимо. Для en/zh вирішуємо перед етапом 5 |
