# 1 Стек

| Шар | Рішення | Примітка |
|---|---|---|
| Рушій представлення | **Godot 4.x, .NET-версія** | На старті зафіксувати конкретну мінорну версію й оновлюватися лише з причини. [Перевірити: актуальну стабільну 4.x] |
| Мова | **C#** | Версія .NET — та, яку вимагає обраний Godot. [Перевірити; на момент моїх знань це .NET 8] |
| Ядро | Бібліотека класів Core без залежностей від Godot | Godot-проєкт посилається на неї через ProjectReference |
| Дані контенту | **YAML** + YamlDotNet (MIT) | Коментарі, багаторядковий текст, зручно для ручного редагування |
| Збереження | **JSON** через System.Text.Json | Вбудований у .NET, з полем версії |
| Тести | xUnit або NUnit | Кожна система ядра покривається тестами з фіксованим сидом |
| Headless-симулятор | Консольний застосунок Sim.Cli | Масові прогони ботами, на виході JSONL/CSV |
| Аналітика балансу | **Python**: pandas, matplotlib/plotly, Jupyter | Читає вивід Sim.Cli. Python лише в інструментах, не в грі |
| Steam | Steamworks.NET або GodotSteam | [Перевірити: стан підтримки Godot 4 .NET перед етапом 5]. У демо потрібен мінімум |
| Шрифти | Noto Sans + Noto Sans CJK як fallback | [Перевірити ліцензію OFL і розмір CJK-шрифтів у збірці] |
| Контроль версій | Git (GitHub/GitLab, приватний репозиторій) | Git LFS для ассетів, якщо їхній обсяг почне заважати |
| CI (опційно) | GitHub Actions: тести + валідатор контенту на push | [Перевірити ліміти безкоштовного тарифу] |

**Обґрунтування.** Легкий рушій під UI-важку 2D-гру. Ліцензія MIT без відрахувань. Одна мова для ядра, тестів, симулятора і гри. Ядро не залежить від рушія, тому заміна рушія зачепить лише шар представлення.

**Відомий ризик стеку.** ШІ-асистенти плутають API Godot 3 і 4 та пропонують GDScript замість C#. Протидія: тонкий Godot-шар і постійні інструкції асистенту в репозиторії (див. розд. 12.3).

## 1.1 Структура репозиторію

```
/src
  /Core            — правила гри, стан, системи, RNG, завантаження контенту
  /Core.Tests      — тести ядра
  /Sim.Cli         — headless-прогони, боти, експорт метрик
  /Tools.Validate  — CLI-валідатор контенту (або підкоманда Sim.Cli)
/game              — Godot-проєкт (UI, сцена бою, ввід, аудіо)
/content           — YAML-дані: техніки, вороги, події, баланс
/loc               — таблиці локалізації (uk, en, zh)
/analysis          — Python-ноутбуки й скрипти аналізу
/docs              — дизайн- і техдокументи, інструкції для ШІ-асистента
```
