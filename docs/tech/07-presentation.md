# 7 Представлення (Godot-шар)

- **UI** на Control-вузлах і контейнерах. Одна тема (Theme) для всього. Вкладені тултипи для розкладки модифікаторів.
- **Сцена бою:** гекс-поле, токени, підсвітка досяжності, зон контролю, траєкторій і цілей. Реалізація — TileMapLayer з гексагональною формою тайлу або власне малювання. Рішення ухвалюємо в прототипі на основі зручності оверлеїв.
- **Карта регіону** — граф вузлів.
- **Анімації мінімальні:** переміщення, спалах удару, числа шкоди. Час анімацій не впливає на ядро.
- **Інструкції для ШІ-асистента** в /docs/ai-guidelines.md:
   - «Godot 4.x, C#, не GDScript, не Godot 3»;
   - «ядро не залежить від Godot»;
   - «UI читає лише PlayerView»;
   - «жодного рандому поза потоками RNG».

## 7.1 Ассети (ШІ-генерація)

- Стильовий гайд: палітра, рамки, формат портретів та іконок, фіксовані промпти й сиди генератора, постобробка до єдиного розміру й палітри.
- **Обсяг для демо:** іконки технік, предметів і стихій; портрети-токени ворогів і NPC; кілька фонів для карти й бою; елементи UI.
